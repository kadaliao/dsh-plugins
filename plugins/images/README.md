# Images has moved

Images now lives in its own repository: **[kadaliao/dsh-images](https://github.com/kadaliao/dsh-images)**.
Install it from the [DSH Plugins](https://github.com/kadaliao/dsh-plugins) index in Discover, or paste
`@kadaliao/dsh-images` into the plugin manager.

Nothing changes for an install you already have. Its source up to the move is in this repository's
history, and the versions in the index that point here keep installing.
